# Todo List Application

A clean and interactive Todo List application built with vanilla JavaScript, HTML, and CSS. This application helps you manage your daily tasks with a beautiful user interface and smooth animations.

## Features

- Add new tasks
- Mark tasks as complete/incomplete
- 🗑Delete individual tasks
- Complete all tasks with one click
- Local storage persistence
- Smooth animations and transitions
- Responsive design

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser

## Usage

- **Adding a Task**: Type your task in the input field and click "Add" or press Enter
- **Completing a Task**: Click the checkbox next to the task
- **Deleting a Task**: Click the "Delete" button next to the task
- **Complete All**: Use the "Complete All" button to toggle all tasks between completed and incomplete states

## Technical Details

The application is built using:
- HTML5
- CSS3 (with animations and transitions)
- Vanilla JavaScript
- Local Storage for data persistence
